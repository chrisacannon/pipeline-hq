What this does
A job application toolkit built on the Claude API: a JD screener, resume tailor, and application tracker in one place.

Step 1 — Screen: Paste a job description and get an instant match score (1-10), verdict (apply / review before applying / pass), salary recommendation, fit reasons, identified gaps, and a plain-language summary. Scoring combines general judgment with whatever guidance you've given in the Resume & rules tab.

Step 2 — Tailor (optional, score 5+): Generates a tailored resume and cover note based on your stored resume, the job description, and your custom rules. Also flags any claims worth pressure-testing for accuracy before submitting.

Tracker: Log every application — status, salary, next action, notes — with CSV export/import, a dark mode independent of the rest of the page, and an "Active" filter that correctly excludes rejected/withdrawn/pending entries.

Using this tool: Enter your Anthropic API key (get one at console.anthropic.com), then paste any job description and screen it. Each screening costs roughly $0.005-0.01. Resume + cover note generation adds another $0.01-0.02.

Setup & your data
Built for anyone to pick up and use with their own background.

The first time you open this page, you'll paste in your resume and answer a short set of optional questions about how you'd like roles scored. Both fields start blank — you can peek at Chris Cannon's actual resume and his answers to those same questions via the "See an example" links, without them ever landing in your own fields. Your answers are saved in this browser's local storage, so they're there the next time you open the page on this device. Nothing is uploaded to a server; the only network call this page makes is directly from your browser to Anthropic's API, using your own key. Use "Start over" in the Resume & rules tab to clear your saved data and go through setup again — useful if you're screening for a different person or want to start fresh.
